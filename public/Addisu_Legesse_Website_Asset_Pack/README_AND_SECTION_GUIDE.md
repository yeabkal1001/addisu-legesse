# Addisu Legesse — Website Asset Pack

This pack is a starting library for the artist portfolio. It combines photos/screenshots supplied in this conversation, crops and editorial treatments derived from those supplied photos, generated visual-design references, and reusable abstract background textures.

## Suggested site map and asset usage

1. **Hero / opening frame** — use a wide, real studio or live-performance image from `01-hero/` or `02-about-artist/`; keep the artist's face visible and leave a dark, uncluttered side for live HTML text. Avoid baking text into the image.
2. **Artist biography** — use `02-about-artist/` portrait crops. Resume positioning: recording artist, vocalist, keyboardist, drummer; contemporary Ethiopian sound blending traditional melodies with modern urban production.
3. **Discography / featured album** — use the official *Mastawesha* album art from the official music platforms (linked below) and a 14-track album presentation. Do not substitute the generated website concepts for official cover art.
4. **Singles / music player** — use official artwork/links for “Ewedshalew,” “Enjori,” “Enja,” and “Etu”; the resume lists approximate view counts of 8.5M+, 8.2M+, 6.4M+, and 5.1M+ respectively. Verify all counts before publishing.
5. **Live / performance section** — use `04-live-performance/` photos and official live-video embeds.
6. **Editorial gallery / press** — use `05-gallery-and-editorial/` as visual treatments and crops; retain originals and get approval for public-facing use.
7. **Backgrounds / transitions** — use `06-backgrounds-and-textures/` as CSS background layers, subtle overlays, or section transitions.
8. **Design references** — `07-reference-designs/` contains AI-generated mockups from the creative exploration; these are references, not authentic photographs or final web layouts.
